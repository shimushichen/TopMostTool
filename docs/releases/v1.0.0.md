# TopMostTool 1.0.0

首次公开发行：Windows 11 x64 窗口置顶与截图贴图工具。

## 下载与使用

- 下载 `TopMostTool.exe` 直接运行，或解压 `TopMostTool-1.0.0-win-x64.zip`。
- 程序为自包含单文件，无需安装 .NET Runtime，启动后驻留系统托盘。
- `Ctrl + Space` 切换窗口置顶；`Ctrl + Shift + S` 框选截图贴图；右键托盘可设置快捷键和批量管理。
- 关闭贴图或退出前请先保存需要的图片。更新时先从旧实例托盘正常退出。

## 本版内容

- 普通窗口置顶、跟随图钉、退出恢复及当前用户开机启动。
- 区域截图贴图、拖动缩放、原图复制、PNG 保存及多图管理。
- 统一菜单与圆角控件，使用已确认的青绿图钉及各项操作图标。
- 修复 PNG DPI 引起的图钉裁切、最大化边界及标题栏垂直定位问题。
- 提供标准源码结构、Windows CI、构建和回归说明，使用 MIT 许可证。
