# TopMostTool 2.0.0

全新视觉与交互大版本升级：Windows 11 x64 窗口置顶与截图贴图工具。

## 下载与使用

- 下载 `TopMostTool.exe` 直接运行，或解压 `TopMostTool-2.0.0-win-x64.zip`。
- 程序为自包含单文件，无需安装 .NET Runtime，启动后驻留系统托盘。
- 左键或右键点击托盘图标可打开右下角控制中心浮窗；`Ctrl + Space` 切换窗口置顶，`Ctrl + Shift + S` 框选截图贴图。
- 关闭贴图或退出前请先保存需要的图片。更新时请先从旧实例托盘退出。

## 本版更新

- **全新托盘控制中心浮窗**：固定锚定于屏幕右下角，集成实时状态胶囊、快捷操作大卡片、最多 3 行可滚轮滚动的置顶窗口列表、贴图一键清理与原生风格开机启动开关。
- **统一苹果极简浅色界面**：全面重做 **关于页**、**快捷键设置页**（支持键帽式修饰键点选）与 **截图贴图顶栏**（纯白分段缩放与操作胶囊），与 Windows 11 原生标题栏无缝融合，并引入统一单色矢量图标体系。
- **全新液态玻璃悬浮叠层图标**：以珍珠银白液态玻璃 + 蔚蓝悬浮顶层全面替换旧版青绿图钉，兼顾浅色界面与深色任务栏的高对比清晰度。
- **底层渲染细节修复**：根治所有圆角按钮/卡片右侧与底部边框裁切问题、消除无边框窗口 DWM 双层圆角冲突、修正贴图右键菜单文字垂直居中。

## 验证说明

本版在 Windows 11 x64（120 DPI）下完成 0 警告 0 错误构建，通过渲染（含新图标清晰度与圆角按钮四边像素对称检测）、界面布局与浮窗（740 项）、菜单与快捷键（38 项）、非模态关于页交互（18 项）、原始透明层像素（6 项）及发布包启动与原生图标逐像素核验（7 项）。
